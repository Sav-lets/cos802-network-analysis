# COS802: Network Analysis: Community Detection and Influence Maximization

## Project Overview

This research project investigates community detection, influential nodes, and information diffusion in social and document networks.

It compares community detection algorithms, evaluates methods for identifying influential nodes, and uses Natural Language Processing (NLP) to explore topic-specific influence.

## Research Questions

1. **Community Detection:** How do Louvain, spectral clustering, and label propagation compare in community quality, stability, and runtime?
2. **Influencer Identification:** Do centrality measures identify the same influential nodes as diffusion-based influence maximization?
3. **Information Diffusion:** How does community structure affect the spread of information through networks?
4. **NLP and Topic Expertise:** How can extracted topics and keywords help identify influential communities for specific topics?
